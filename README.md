# 🤖 Bot de Formalização de Chamados  

Este bot usa **IA** para formalizar chamados de TI no Discord, estruturando as informações de forma clara e objetiva.  

---

## 📥 1. Clonar o Repositório  

```sh
git clone https://github.com/seu-usuario/nome-do-repositorio.git
cd nome-do-repositorio
```

---

## 📦 2. Instalar Dependências  

```sh
npm install
```

---

## 🔑 3. Configurar Variáveis de Ambiente  

Crie um arquivo `.env` e adicione suas credenciais:  

```sh
DISCORD_TOKEN=seu_token_aqui
GEMINI_API_KEY=sua_chave_gemini_aqui
CLIENTE_ID=seu_cliente_id_aqui
GUILD_ID=seu_servidor_aqui
